# Chat — 多模型 AI 聊天平台

一个自建的**多模型 AI 聊天平台**，支持多服务商模型聚合切换、流式对话、会话持久化、多模态（图片）理解，以及内置 RAG 知识库问答。

> 当前状态：技术设计阶段，尚未开始编码。所有设计决策记录在 `docs/` 目录下。

## 技术栈速览

- **前端**：React 18 + Vite + TypeScript + Tailwind CSS + shadcn/ui
- **后端**：Node.js + Fastify + TypeScript + Vercel AI SDK
- **数据库**：PostgreSQL + pgvector
- **ORM**：Drizzle
- **文件存储**：本地磁盘（预留 S3/MinIO 接口）
